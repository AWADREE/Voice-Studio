# Project asset provenance

On 2026-11-08 the project owner explicitly confirmed that the original background was generated by us for their project and authorized keeping this fork public with the background and matching project assets. This authorization covers the night-sky raster and ported star animation, not personal voices, audio, settings, credentials, or logs.

- assets/night-sky-stars-removed.png: original generated project background, unchanged bytes from the established local Voxover installation.
- night-sky.js: established Voxover animation and UI behavior; only asset URLs are made portable.
- assets/app-icon/: geometric microphone icon authored for Voxover.
- Font files: third-party SIL OFL fonts; full copyright/license texts are bundled separately.

No personal voice prompts, reference recordings, generated commentary, model weights, private configuration or logs are included.
